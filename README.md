# Uni-Run: Marathon & Virtual Run Coordinator

## CSC584 Enterprise Programming

This repository contains the storyboard for the CSC584 group project titled **Uni-Run: Marathon & Virtual Run Coordinator**.

The purpose of this storyboard is to show the proposed interface design, system flow and main modules before the actual system development phase.

---

## Project Overview

Uni-Run is a web-based system designed to manage marathon and virtual run events. The system allows users to register as participants, view available running events, register for events, submit running results and view their participation status.

The system also provides an administrator module where the admin can manage events, manage participants and verify submitted running results.

---

## Project Objectives

The objectives of this project are:

1. To design a web-based marathon and virtual run coordination system.
2. To allow participants to register and join running events online.
3. To allow participants to submit running results for virtual run events.
4. To allow administrators to manage events and participant records.
5. To allow administrators to verify submitted running results.
6. To apply Enterprise Programming concepts using web-based system design.

## Main System Modules

### 1. Participant Module

The participant module allows users to:

- Register a new account
- Login to the system
- View available events
- Register for marathon or virtual run events
- Submit running results
- View registration and result status

### 2. Administrator Module

The administrator module allows admin users to:

- View admin dashboard summary
- Manage running events
- View and manage participant records
- Verify submitted running results
- Approve or reject participant results

---

## CRUD Functions

The storyboard includes CRUD functions for the administrator module.

| Function | Description |
|---|---|
| Create | Admin can add new running events |
| Read | Admin can view event and participant records |
| Update | Admin can update event details, participant status and result verification |
| Delete | Admin can delete event or participant records |
