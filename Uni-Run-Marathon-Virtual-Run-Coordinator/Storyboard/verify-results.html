Verification Process

1. Admin views submitted running result.

2. Admin checks completion time and uploaded proof.

3. Admin approves valid result or rejects invalid result.

4. Participant result status is updated in the system.

Storyboard Explanation

This page allows the administrator to verify running results submitted by participants. Admin can view the submitted distance, completion time, proof screenshot and result status.

In the actual system, result verification will be connected to Servlet and database operations. The admin can approve or reject results and the updated status will be displayed in the participant dashboard.
