CRUD Function Shown

This storyboard page shows the event management module for administrators. It includes the basic CRUD functions required in the actual system.

Create: Admin can add a new marathon or virtual run event.

Read: Admin can view the list of existing events.

Update: Admin can edit existing event details.

Delete: Admin can remove an event from the system.

Storyboard Explanation

This page allows the administrator to manage all running events in the system. The admin can enter event details such as event name, category, distance, date, registration fee, maximum participants and event description.

In the actual development stage, this page will connect to Servlet and database operations to save, retrieve, update and delete event records.
