Storyboard Explanation

This page allows participants to submit their running results after completing a marathon or virtual run. Participants can enter distance completed, completion time, run date and upload proof screenshot.

In the actual system, uploaded proof and result details will be stored in the database and verified by the administrator.

Expected System Process

1. Participant selects registered event.

2. Participant enters running result details.

3. Participant uploads proof screenshot.

4. Admin verifies submitted result.
