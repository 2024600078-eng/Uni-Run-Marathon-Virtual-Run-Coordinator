Welcome to Uni-Run

Uni-Run is a web-based system designed to manage marathon and virtual run events for university students, staff and the public. The system allows participants to register for events, view event details, check registration status and track run participation.

This storyboard shows the planned interface and system flow before the actual development using Servlet, JSP and database integration.
