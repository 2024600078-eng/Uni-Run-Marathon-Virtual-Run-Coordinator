CRUD Function Shown

This storyboard page shows the participant management module for administrators. It includes basic CRUD actions for participant records.

Create: Participant records are created when users register for an event.

Read: Admin can view participant registration details.

Update: Admin can update participant registration status.

Delete: Admin can remove incorrect or duplicate participant records.

Storyboard Explanation

This page allows the administrator to view and manage participant information. The admin can check participant details, event registration records and registration status.

In the actual system, participant data will be retrieved from the database and managed through Servlet and JSP pages.
