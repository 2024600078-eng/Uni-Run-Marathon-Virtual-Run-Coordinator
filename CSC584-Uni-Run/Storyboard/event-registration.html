Storyboard Explanation

This page allows participants to register for a selected marathon or virtual run event. Participants need to provide event selection, run category, t-shirt size, emergency contact number and health declaration.

In the actual system development, this registration form will submit data to a Servlet. The registration details will then be saved into the database and shown in the participant dashboard.

Expected System Process

1. Participant selects an available event.

2. Participant fills in registration details.

3. System saves registration record.

4. Participant can view registration status in dashboard.
